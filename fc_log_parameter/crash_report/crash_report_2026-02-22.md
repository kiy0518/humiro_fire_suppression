**배경**: QGC에 남아있던 이전 테스트 좌표(35.9054337, 128.8026989)가 타겟으로 전송됨 (932m 거리).

1번 기체는 조종사가 3초 만에 개입하여 생존했지만, 개입이 늦었다면 2번과 같은 전복 가능성 있음.

**소프트웨어 문제점** (2, 3번 기체와 공통):
1. 이동 시작 시 점진적 가감속(S-curve/ramp) 없이 목적지를 즉시 setpoint으로 설정
2. 목적지 거리에 대한 안전 제한 없음 (932m가 그대로 통과)
→ 거리와 무관하게 부드러운 가속 프로파일 적용 필요

#### 기체 3번이 생존한 이유 (vs 2번 추락)

| 비교 항목 | 기체 2번 (추락) | 기체 3번 (생존) |
|:----------|:---------------:|:---------------:|
| 이륙 목표 고도 | **2.09m** | **1.30m** |
| 수평 이동 거리 | **7.3m** | **2.0m** |
| 최대 roll 각도 | **-70°** → 전복 | **-31°** → 회복 |
| 이동 명령 시점 | 이륙 후 0.2초 | 이륙 후 0.2초 (동일) |
| 결과 | 제어 불능 → 추락 | 진동 → 조종사 개입 |

**기체 3번이 생존한 핵심 차이**: 수평 이동 거리가 2m로 짧아서 PX4가 요구한 기울기가 -31° 수준에 그침.
7.3m를 이동해야 했던 2번은 -70°까지 기울어져 복구 불가능.

**그러나 개입이 없었다면**: roll이 ±10°로 계속 진동하는 불안정 상태였고,
다음 목적지 명령이 더 먼 거리였다면 2번과 동일하게 전복 추락했을 가능성이 높음.

### 3-4. 이륙 관련 문제 — 계단식 setpoint

**PX4 기본 이륙 (AUTO_TAKEOFF)**:
```
MPC_TKO_SPEED  = 1.5 m/s  (목표 이륙 속도)
MPC_TKO_RAMP_T = 3초       (추력 램프업 시간)
→ 부드럽게 상승: 0 → 1.5m/s까지 3초에 걸쳐 가속
```

**현재 OFFBOARD 이륙 (우리 코드)**:
```
t=5.02s: setpoint z = +0.92  (지면)
t=5.22s: setpoint z = -2.09  (2.09m 상공)  ← 순간 점프!

PX4 위치 컨트롤러 반응:
  → 2.09m 위치 오차 발생 → 최대 추력 출력
  → MPC_Z_VEL_MAX_UP = 3.0m/s까지 급상승
  → MPC_TKO_RAMP_T 램프업 무시 (OFFBOARD이므로)
```

**결과**: 이륙이 매우 급격하고 거침. 3대 모두 동일.
- 기체 2: 최대 상승속도 3.11 m/s
- 기체 3: 최대 상승속도 2.97 m/s
- 급격한 이륙 → 자세 불안정 → 수평 이동 명령 시 취약

## 5. 기체 배치 순서 영향 분석

테스트 시 기체 배치가 의도(2-1-3)와 다르게 3-1-2로 배치된 경우:

```
의도한 배치:         실제 배치:
  [2] [1] [3]         [3] [1] [2]
 팔로워 리더 팔로워   팔로워 리더 팔로워
```

**편대 비행에서 배치가 의미하는 것**:
- 리더(1번)의 위치를 기준으로 팔로워의 오프셋이 결정됨
- MAV_SYS_ID: 1번=1, 2번=2, 3번=3 (고정)
- 편대 오프셋은 MAV_SYS_ID 기반으로 계산됨

**배치 순서가 뒤바뀌면**:
- 기체 2(SYS_ID=2)가 원래 기체 3 위치에 있음
- 기체 3(SYS_ID=3)이 원래 기체 2 위치에 있음
- 편대 오프셋이 반대 방향으로 계산됨
- → 팔로워들이 서로의 목적지로 교차 비행하게 됨
- → 충돌 위험 또는 과도한 이동 거리 발생 가능

**이번 추락과의 관계**:
기체 2번의 목적지(5.81, 6.01)가 원래 기체 3 위치의 목적지였을 가능성이 있음.
잘못된 배치로 인해 기체 2가 반대편 목적지까지 7.3m를 이동해야 했고,
이것이 저고도 전복의 직접적 원인이 되었을 수 있음.

## 6. 파라미터 안전 설정 — `CBRK_FLIGHTTERM = 121212` 위험성

```
CBRK_FLIGHTTERM = 121212 → Flight Termination 비활성화
```

**의미**: Failure Detector가 위험(roll > 60°)을 감지해도 모터를 정지하지 않음.

**기체 2번 사고에서의 영향**:
```
t=10.73s  Failure Detector 발동 (roll > 60°)
          ↓
          CBRK_FLIGHTTERM=121212 → 모터 정지 안됨
          ↓
          뒤집힌 상태에서 모터 전력 회전 계속
          ↓
          추가 기체 파손 + 주변 위험
```

**`CBRK_FLIGHTTERM = 0`으로 변경해야 하는 이유**:
- 뒤집힌 상태에서 모터 즉시 정지 → 2차 파손 방지
- 낙하 중 프로펠러 회전에 의한 인체/기물 파손 방지
